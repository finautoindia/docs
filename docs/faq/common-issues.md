## 1. What does the issue  
**"Tally Connection Error: Ensure that Tally is running ODBC server on port: 9000"** mean?

**Answer:**  
This error indicates that:

- The **Tally software is not running**, or  
- The **ODBC setting (port 9000)** is not enabled in Tally, or  
- The **Finauto plugin (tcodes.tcp)** has not been installed correctly in Tally.

📌 To resolve this:
- Ensure Tally is open and the **ODBC port (9000)** is active.  
- Check if the plugin is added in Tally via `Help → F4 Add-Ons`.

View ODBC Setup under installation</a>

## 2 What does  
**"Finauto username and/or password is not valid. Please configure from Configuration → Settings"** mean?

**Answer:**  
This means:

- Your **Finauto API key has expired**, or  
- It has been **regenerated by another user** in your organization.

📌 To resolve this:
- Generate a new API key from your login at  
  🔗 [https://www.finautoindia.com/user/login](https://www.finautoindia.com/user/login)  
- Go to `Configuration → Settings` in the client software.
- Paste the new API key and **click the "Update"** button under **Service Settings**.

## 3. Does Fianuto have Rounding off feature to convert the Balance Sheet values into denominations like Hundreds, Thousands, Lakhs, or Millions?

**Ans:** ✅ Yes, Finauto facilitates this feature conveniently.

After generating the Balance Sheet in Excel format, you will find a file named:

📄 **MASTER SHEET**

Inside the MASTER SHEET:

- Cell `F1` displays the label: **Convert To**
- Cell `F2` provides a dropdown menu to select your preferred denomination:
    - Hundreds
    - Thousands
    - Lakhs
    - Millions

This allows you to instantly convert the entire balance sheet figures to a desired scale for reporting or presentation purposes.

> 💡 No need to modify formulas manually — the conversion is automated based on your selection!

## 4. What does the issue "Income tax number not set" mean?

**Ans:** ⚠️ This error occurs when the **PAN (Permanent Account Number)** is not configured in Tally.

To resolve this:

1. Open **Tally**.
2. Navigate to `F11 → Features`.
3. Go to **More Details**.
4. Ensure the **PAN** field is correctly filled in.

> 🔍 PAN is a mandatory field required by Finauto to fetch or validate income tax-related data from Tally.

## 11.What is the "Carry Code" feature and how does it work?
The **Carry Code** feature in Finauto ensures consistency in ledger classification year-on-year.

It performs the following actions:

- ✅ **Auto-applies the same ledger codes** from the previous financial year to current year ledgers **if the ledger names match**.
- 🔄 **Tracks changes in debit and credit balances** and adjusts mapping accordingly.
- 🧠 Saves users time by avoiding repeated manual classification of ledgers each year.

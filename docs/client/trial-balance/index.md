# Trial balance

Review and edit imported ledgers and stock items before generating financial statements.

<div class="fa-docs-link-grid" markdown="1">

- [Ledgers](ledgers.md) — chart of accounts, auto-coding, periodic balances
- [Stock Items](stock.md) — inventory lines from import

</div>

## Typical workflow

1. [Import](../import/excel.md) trial balance data for the active company and FY.
2. Open [Ledgers](ledgers.md) and verify grouping codes.
3. Review [Stock Items](stock.md) if inventory is in scope.
4. Generate the [balance sheet](../reports/balance-sheet.md).

# Aging

Manage trade receivables and payables aging from voucher data and download Excel aging reports.

<div class="fa-docs-link-grid" markdown="1">

- [Vouchers](vouchers.md) — refresh aging voucher data
- [Trade Payables](payables.md) — supplier outstanding
- [Trade Receivables](receivables.md) — customer outstanding
- [Report](report.md) — download aging Excel

</div>

## Typical workflow

1. Update [vouchers](vouchers.md) for the selected company and period.
2. Review [payables](payables.md) and [receivables](receivables.md) grids.
3. Generate the [aging report](report.md) for auditors or management.

📊 Aging Report
The Aging Report helps in tracking outstanding balances and overdue amounts. It is generated based on voucher entries imported into the software.

📥 Voucher Import for Aging
🧾 Tally Users
When importing data from Tally, vouchers are automatically imported along with other records.

Make sure the option “Import Data for Aging” is checked during Tally data import.

Vouchers are used to calculate the outstanding amounts and due periods.

📄 Non-Tally Users
For non-Tally users, voucher data can be imported through Excel templates.

Go to Ageing → Vouchers.

Download the template from the bottom of the screen.

Fill in the required voucher details and import using the provided tool.

📈 Viewing Aging Reports
Navigate to the “Ageing” tab in the software to view reports.

Reports are automatically plotted in the financial statements generated by the system.

Outstanding balances are grouped by duration (e.g., 0–30 days, 31–60 days, etc.).

🔁 Handling Previous Year Balances
If there are balances outstanding for more than one year, import previous year’s data as well.

This ensures accurate and complete aging analysis.

<h2 style="font-weight: bold; color: #0073e6;">⚙️ Settings Tab</h2>

The Settings Tab includes various configuration options that help the user control data access, report generation behavior, and integration settings.

<h3 style="color: #e67e22; font-weight: bold;">🔑 API Key</h3>

This option allows users to update their API key every 30 days.

The key is generated through the Finauto client login.

Steps:
Visit: <a href="https://www.finautoindia.com/user/login" target="_blank" style="color: #0073e6; font-weight: bold;">
  Login to Finauto Client
</a>

Login with your credentials.

Generate a new API key.

<h3 style="color: #e67e22; font-weight: bold;">📅 Enable Quarterly or Half-Yearly Balance Sheets:</h3>

Tick this checkbox if you want to generate Balance Sheets on a Quarterly or Half-Yearly basis.

Once enabled, reporting options will allow period-specific balance sheet views.

<h3 style="color: #e67e22; font-weight: bold;">☁️ Generate Reports in Cloud</h3>

Enable this option to generate reports on the cloud for:

Faster performance

Easier troubleshooting

Quicker resolution of balance sheet errors

Recommended for larger files or users needing remote support.


<h3 style="color: #e67e22; font-weight: bold;">🤖 Enable Auto Code Feature</h3>

Use this to auto-code your Trial Balance:

Automatically maps ledgers using preset logic.

Saves time during Excel imports or when codes are missing in Tally.

Use Cases:

No manual code entry in Tally required.

Avoid manual punching in Excel Trial Balances.

<h3 style="color: #e67e22; font-weight: bold;">📁 Tally Settings</h3>


Tally Install Location

Specify the folder where Tally is installed.

Example: C:\Program Files\TallyPrime

Tally ODBC Port:

This must be set to 9000, which is Tally's default ODBC port.

Required for Tally-to-software connectivity.
